# Navigation and interaction rules

- Five global destinations: Home, Applicants, Jobs, Reports, Settings.
- Applicants begins with jobs. The selected job owns filters, stage tabs, ranking and downloads; no pooled all-job ranking is presented.
- New and Shortlisted are display names for existing Application Review and Screening values. Historical data, exports and API values retain the stored values.
- The URL records the selected job, filters, page and applicant. The interview shortcut also records its initial action; Back/Forward restores context.
- Primary job actions are View applicants and Edit job. Secondary actions appear under Actions.
- Applicant primary actions are Shortlist, Request interview and Add note. Opening interview setup sends nothing; Send booking link requires the effective recruiter mailbox, company Google prerequisite and chosen or pinned calendar.
- AI review leads with supported requirements, strengths and gaps. Exact source evidence and optional manual tools expand on demand.
- Home emphasizes active jobs and applicants waiting for initial review. Help/privacy requests are in Settings.
- Owner controls company settings; head recruiters manage the team. Authorized staff retain their existing hiring-record access.
- Job autosave, draft restoration and unsaved-navigation protection remain active. A saved draft does not publish a role.
- Mobile controls wrap without expanding the document; menus remain within the viewport. Record panels hidden by tabs have no layout height.
