Noto Sans Regular and Bold are bundled for private, server-generated hiring PDFs.
Source: https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans
License: SIL Open Font License 1.1, included in OFL.txt.

These fonts support Latin, Greek and Cyrillic text. Unsupported characters are
printed as explicit Unicode code points rather than silently lost. Original
documents and application answers remain unchanged in private storage.
